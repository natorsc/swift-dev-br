Aprender os atalhos de teclado do macOS pode aumentar bastante sua produtividade no dia a dia. Seja para navegar entre aplicativos, utilizar o Terminal, editar textos ou gerenciar múltiplas janelas, dominar os atalhos certos faz muita diferença.

Para quem está migrando do Windows ou começando a utilizar um Mac agora, alguns atalhos podem parecer confusos inicialmente, principalmente por causa das teclas Command, Option e Control.

Neste guia, você vai aprender os principais atalhos do macOS de forma prática e organizada.

## Entendendo as teclas do macOS

Antes de começar, é importante entender a equivalência entre um teclado tradicional ABNT2 e as teclas utilizadas no macOS.

## Equivalência entre teclado ABNT2 e macOS

| Tecla no PC | Equivalente no macOS | Símbolo | Uso mais comum |
|---|---|---|---|
| Windows | Command | ⌘ | Principal tecla de atalhos do macOS |
| Ctrl | Control | ⌃ | Muito usada no Terminal |
| Alt | Option | ⌥ | Navegação e caracteres especiais |
| Shift | Shift | ⇧ | Seleção e letras maiúsculas |
| Backspace | Delete | ⌫ | Apagar para trás |
| Delete | Forward Delete | ⌦ | Apagar para frente |
| Fn | Fn | fn | Funções especiais |

## O que significa cada símbolo nos atalhos?

O macOS normalmente exibe os atalhos usando símbolos em vez dos nomes das teclas.

Os mais comuns são:

- ⌘ = Command.
- ⌥ = Option.
- ⌃ = Control.
- ⇧ = Shift.
- ⌫ = Delete.
- ⌦ = Forward Delete.

Depois de alguns dias utilizando o sistema, esses símbolos acabam se tornando naturais.

## Exemplos rápidos para quem vem do Windows

Se você migrou recentemente para o macOS, estes atalhos ajudam bastante na adaptação inicial:

| Atalho no macOS | Equivalente aproximado no Windows |
|---|---|
| (Command) ⌘ + C | Ctrl + C |
| (Command) ⌘ + V | Ctrl + V |
| (Command) ⌘ + X | Ctrl + X |
| (Command) ⌘ + Z | Ctrl + Z |
| (Command) ⌘ + A | Ctrl + A |
| (Command) ⌘ + Espaço | Windows + Espaço |

Na prática, a tecla (Command) ⌘ Command substitui boa parte do uso do Ctrl no Windows.

## Atalhos essenciais do macOS

Esses são os atalhos mais utilizados no dia a dia.

## Navegação entre aplicativos e janelas

| Ação | Atalho |
|---|---|
| Alternar entre aplicativos | (Command) ⌘ + Tab |
| Alternar entre janelas do mesmo app | (Command) ⌘ + ` |
| Fechar janela atual | (Command) ⌘ + W |
| Minimizar janela | (Command) ⌘ + M |
| Ocultar aplicativo atual | (Command)⌘ + H |
| Forçar encerramento de aplicativos | (Command) ⌘ + (Option) ⌥ + Esc |

O atalho (Command) ⌘ + Tab é provavelmente um dos mais importantes para produtividade no macOS.

## Gerenciamento de janelas e desktops virtuais

O macOS possui excelente suporte para multitarefa utilizando Mission Control e Spaces.

| Ação | Atalho |
|---|---|
| Abrir Mission Control | (Control) ⌃ + ↑ |
| Mostrar janelas do app atual | (Control) ⌃ + ↓ |
| Ir para próximo desktop virtual | (Control) ⌃ + → |
| Ir para desktop anterior | (Control) ⌃ + ← |
| Mostrar área de trabalho | F11 ou fn + F11 |

## O que é o Mission Control?

O Mission Control é um recurso do macOS que exibe:

- Todas as janelas abertas.
- Aplicativos em execução.
- Desktops virtuais.
- Apps em tela cheia.

Ele facilita bastante a organização do ambiente de trabalho.

## Atalhos para edição de texto

Esses atalhos funcionam na maioria dos aplicativos do macOS.

## Navegação em textos

| Ação | Atalho |
|---|---|
| Ir para início da linha | (Command) ⌘ + ← |
| Ir para final da linha | (Command) ⌘ + → |
| Ir para início do documento | (Command) ⌘ + ↑ |
| Ir para final do documento | (Command) ⌘ + ↓ |
| Voltar uma palavra | (Option) ⌥ + ← |
| Avançar uma palavra | (Option) ⌥ + → |

Os atalhos com ⌥ Option são extremamente úteis para edição rápida de textos e códigos.

## Seleção de texto

| Ação | Atalho |
|---|---|
| Selecionar palavra anterior | (Shift) ⇧ + (Option) ⌥ + ← |
| Selecionar até início da linha | (Shift) ⇧ + ⌘ + ← |
| Selecionar até final da linha | (Shift) ⇧ + ⌘ + → |

## Atalhos úteis no Terminal

Para quem utiliza Terminal no macOS, alguns atalhos podem acelerar bastante o fluxo de trabalho.

| Ação | Atalho |
|---|---|
| Ir para início da linha | (Control) ⌃ + A |
| Ir para final da linha | (Control) ⌃ + E |
| Apagar palavra anterior | (Control) ⌃ + W |
| Apagar até início da linha | (Control) ⌃ + U |
| Limpar terminal | (Command) ⌘ + K |

Esses atalhos funcionam em shells como:

- Zsh.
- Bash.
- Fish.

## Atalhos do sistema

Alguns atalhos importantes do próprio macOS.

| Ação | Atalho |
|---|---|
| Abrir Spotlight | (Command) ⌘ + Espaço |
| Capturar tela inteira | (Command) ⌘ + (Shift) ⇧ + 3 |
| Capturar área selecionada | (Command) ⌘ + (Shift) ⇧ + 4 |
| Bloquear tela | (Control) ⌃ + (Command) ⌘ + Q |

## Usando o Spotlight corretamente

O Spotlight é um dos recursos mais poderosos do macOS.

Com (Command) ⌘ + Espaço você pode:

- Abrir aplicativos.
- Buscar arquivos.
- Fazer cálculos.
- Converter moedas.
- Pesquisar configurações.
- Abrir documentos rapidamente.

Muitos usuários praticamente substituem a navegação tradicional pelo Spotlight.

## Dicas de produtividade no macOS

Além dos atalhos tradicionais, alguns hábitos ajudam bastante na produtividade.

## Abrindo aplicativos rapidamente

Use:

```bash
(Command) ⌘ + Espaço
````

Depois:

- Digite o nome do aplicativo.
- Pressione Enter.

Isso normalmente é muito mais rápido do que navegar pelo Finder.

## Renomeando arquivos no Finder

Para renomear arquivos rapidamente:

- Selecione o arquivo.
- Pressione Enter.

Simples e extremamente útil.

## Movendo janelas entre desktops

Para mover uma janela para outro desktop virtual:

- Abra o Mission Control com (Control) ⌃ + ↑.
- Arraste a janela para o desktop desejado.

Esse recurso é excelente para organizar ambientes de trabalho.

## Vale a pena aprender os atalhos do macOS?

Sim. Depois de memorizar os atalhos principais, o uso do macOS se torna muito mais rápido e confortável.

Os maiores ganhos normalmente aparecem em:

- Multitarefa.
- Desenvolvimento.
- Edição de textos.
- Uso do Terminal.
- Navegação entre aplicativos.

Além disso, os atalhos ajudam bastante a reduzir a dependência do mouse ou trackpad.

## Conclusão

O macOS possui um excelente conjunto de atalhos de teclado que pode acelerar bastante o fluxo de trabalho no dia a dia.

Para quem está começando, o ideal é memorizar primeiro os atalhos mais usados:

- (Command) ⌘ + Tab.
- (Command) ⌘ + Espaço.
- (Command) ⌘ + C.
- (Command) ⌘ + V.
- (Command) ⌘ + W.

Com o tempo, os atalhos se tornam naturais e o uso do sistema fica muito mais produtivo.
