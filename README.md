## Por que Swift?

A linguagem de programação Swift deixou de ser "apenas a linguagem da Apple" há muito tempo. Hoje, vivemos a era do **Swift Multiplataforma**.

Seja desenvolvendo apps nativos incríveis com [SwiftUI](https://developer.apple.com/swiftui/), construindo backends performáticos com [Vapor](https://vapor.codes) ou explorando o desenvolvimento scripts para Windows e Linux.

O Swift se destaca por ser:

- **Seguro por design:** Evita categorias inteiras de bugs comuns de programação.
- **Rápido:** Performance comparável ao C++, mas com uma sintaxe moderna e limpa.
- **Expressivo:** Permite escrever códigos complexos de forma concisa e legível.
